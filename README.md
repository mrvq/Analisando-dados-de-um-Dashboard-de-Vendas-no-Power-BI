# 📊 Analisando Dados de um Dashboard de Vendas no Power BI

## 🧭 Descrição do Desafio
Este projeto faz parte do curso **"Analisando Dados com SQL Analytics e Power BI"** da [DIO (Digital Innovation One)](https://www.dio.me/).

O objetivo é replicar as páginas desenvolvidas durante o curso e criar uma **terceira página autoral** no Power BI, aplicando conceitos de modelagem, visualização e storytelling com dados.

---

## 🚀 Objetivo da Página 3 — *Análise Global de Vendas*

A terceira página foi desenvolvida com o propósito de explorar insights de desempenho de vendas e lucros por país e segmento.  
Ela inclui três visuais principais:

| Visual | Métrica | Objetivo |
|--------|----------|----------|
| 🗺️ **Mapa 1** | Soma de *Sales* e *Units Sold* por país | Visualizar a distribuição de vendas e volume de unidades vendidas |
| 🗺️ **Mapa 2** | Soma de *Profit* por país | Analisar a lucratividade por região |
| 🥧 **Gráfico de Pizza** | *Profit* por *Segment* | Entender a contribuição de cada segmento no lucro total |

## 🧩 Base de Dados Utilizada
A base `Financials.csv` contém informações financeiras e comerciais, com os seguintes campos principais:

| Campo | Descrição |
|--------|------------|
| `Country` | País |
| `Segment` | Segmento de mercado |
| `Product` | Produto |
| `Sales` | Vendas totais |
| `Units Sold` | Quantidade vendida |
| `Profit` | Lucro obtido |
| `Date` | Data da venda |

📥 Dados originais disponíveis no repositório:  
🔗 [https://github.com/julianazanelatto/power_bi_analyst](https://github.com/julianazanelatto/power_bi_analyst)

---

## 🧠 Insights Obtidos

- Países com maior volume de vendas e lucro: **Estados Unidos e Alemanha**
- Segmento mais lucrativo: **Government**
- Relação direta entre número de unidades vendidas e lucro médio por país
- Possível oportunidade de expansão em países com baixo volume de vendas mas alta margem de lucro
